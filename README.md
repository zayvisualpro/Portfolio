# Portfolio — Zay

Monteur Vidéo & Motion Designer.

🌐 **Site en ligne :** [https://zayvisualpro.github.io/Portfolio/](https://zayvisualpro.github.io/Portfolio/)

---

## 🚀 Fonctionnalités
- Design sombre cinématique avec animations fluides
- Lecteur vidéo interactif intégré (YouTube)
- Filtrage des projets par catégories (Tous, Vidéos Longues, Motion Design, Shorts, Gaming)
- Timeline scrubber interactif
- Formulaire et liens de contact directs

## 🛠️ Stack technique
- **Framework :** React 19 + Vite
- **Styling :** Tailwind CSS v4
- **Icônes :** Lucide React

## 📦 Déploiement
Pour mettre à jour le site en ligne après de nouvelles modifications :
```bash
npm run deploy
```
